# 分诊标签

实施任务的 `Status:` 使用下表的本地标签。技能提到某个分诊角色时，写入对应的标签值。

| 技能角色 | 本地标签 | 何时使用 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交给代理独立实施 |
| `ready-for-human` | `ready-for-human` | 需要由人实施 |
| `wontfix` | `wontfix` | 已决定不处理 |
