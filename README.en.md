# Docker ZeroTier Planet

English | [简体中文](README.md)

Run a self-hosted ZeroTier Planet, Moon, and ztncui network controller in one Docker container. The project supports the current upstream Planet-generation flow only. GitHub Actions tracks the latest stable ZeroTier tag and publishes AMD64/ARM64 images.

> Prefer a managed deployment? See [Hosted services and one-click deployment](#hosted-services-and-partners) below.

## Quick start

Requirements: Linux, Docker Engine, Docker Compose, and a public IPv4 or IPv6 address reachable by clients.

```bash
git clone https://github.com/xubiaolin/docker-zerotier-planet.git
cd docker-zerotier-planet
./deploy.sh install
```

The installer creates `.env`, starts the container, and waits for its health check. A new installation generates a random ztncui administrator password and displays it once. After startup it shows the effective public addresses, Planet endpoints, management URLs, and directly usable Planet/Moon download URLs.

Common commands:

```bash
./deploy.sh status
./deploy.sh logs
./deploy.sh doctor
./deploy.sh upgrade
./deploy.sh reconfigure
./deploy.sh reset-password
./deploy.sh uninstall       # keeps persistent data
```

You can also use Compose directly:

```bash
cp .env.example .env
# Edit .env and verify the public addresses and ports.
docker compose up -d
```

## Default ports

| Port | Protocol | Purpose |
| --- | --- | --- |
| `9994` | TCP/UDP | ZeroTier Planet |
| `3443` | TCP | ztncui management UI |
| `3000` | TCP | Planet/Moon downloads |

Generated artifacts are stored under `data/zerotier/dist/`. The download key is stored at `data/zerotier/config/file_server.key`. The file service accepts both `Authorization: Bearer <key>` and the legacy `?key=<key>` form. Run `./deploy.sh status` to print complete addresses generated from the persisted runtime configuration. Direct download URLs contain the access key and must be protected as credentials.

## Custom Planet on iOS / iPadOS

This is supported. Official ZeroTier mobile clients can load custom root sets (Planet files) starting with version `1.16.0`, so a `planet` generated by this project with ZeroTier Core `1.16.2` can be imported into the official iOS/iPadOS app without jailbreaking the device.

First, encode the binary Planet file as single-line Base64 text on the server:

```bash
base64 -w 0 data/zerotier/dist/planet
```

Then use either import method:

1. Copy the complete Base64 text, open `Settings` → `Add Planet File` in the ZeroTier app, paste it, and confirm.
2. Use the official URL format `https://joinzt.com/addplanet?v=1&planet=<BASE64>`. Open it on the iPhone/iPad and confirm the import, or open it in a desktop browser and scan the generated QR code with the mobile device.

Verify that the custom Planet address and port are reachable from the mobile device before importing it. Here, `1.16.2` is the ZeroTier Core version used to generate the Planet; the required iOS app version is `1.16.0` or newer. See ZeroTier's official [Private Root Servers documentation](https://docs.zerotier.com/roots/#mobile).
